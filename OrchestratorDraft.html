Multi-Agent Turn Routing Modes

1. Host-Directed (AI Router)

Before each turn, the designated Host AI analyzes the recent transcript and outputs a structured JSON routing decision selecting which specialist agent should speak next and why.

2. Round-Robin Sequential

Deterministic fixed-order rotation through every active agent in the registry pool (AEGIS → NOVA → VEX), ensuring equal floor time per round.

3. Manual Operator Override

Automatically pauses the loop after every single turn so the human operator can inspect telemetry, inject guidance, or manually click a Force-Pass Mic button.

Automated 1–10 Consensus Matrix Mathematical Model

Structured Per-Agent Scoring & Verdicts

Each active persona evaluates the target proposal and bus context in parallel, returning a structured JSON payload with:

  • Score 8–10 (APPROVE): High confidence endorsement.
  • Score 5–7 (CONDITIONAL): Viable with specific mitigations.
  • Score 1–4 (REJECT): Critical architectural or security flaw.
Mean Score & Standard Deviation Convergence %

The matrix computes the arithmetic Mean Score ($\mu$) and the population Standard Deviation ($\sigma$) across all agent scores:

Convergence % = clamp(100 - (σ / 4.5) × 100, 0, 100)

If $\mu \ge 7.5$, Convergence $\ge 65\%$, and no agent votes REJECT, the matrix locks CONSENSUS LOCKED.
